# v0.0.66 API 变更日志 — context engine refactor（无 API 变更）

> version: 1.0 · 2026-07-04
> 一句话定位：**本版本无 API 接口变更**——纯内部 refactor（context engine assemble/ingest 协议重构 + session_store EP 化），HTTP 端点契约 + schema + 行为完全不变。
> 关联：tech `specs/tech/version_logs/v0.0.66/change_log.md`（详细技术变更）+ prd `specs/prd/version_logs/v0.0.66.md`（PRD 摘要）。

---

## 1. API 零变更确认

v0.0.66 是 context engine 内部 refactor（default + forked 共用同一套 ingest/assemble 主干逻辑），**不涉及任何 HTTP 端点契约、schema、行为变更**。

复用的既有端点（行为不变）：

| 端点 | 行为 | 本版本影响 |
|---|---|---|
| `POST /session/:id/messages` | 发消息（drainMode='eager' main path） | 零——主干 refactor 后行为 1:1 对齐（system 改由 snapshot.system 独立承载 + loop-stage-llm prepend，wire 形态不变） |
| `POST /session/:id/compact` | 手动 compact | 零——compact 流程不变（forked agent 调 LLM） |
| `GET /session/:id/messages` | 读 transcript | 零——transcript 落库语义不变（持久 SessionStore 不变） |
| `GET /session/:id/usage` | 读 usage view | 零——usage 三分区存储不变（forked in_memory store no-op 不污染主对话 meta） |

## 2. 既有 AT case 适用性

`tests/api/` 下所有既有 AT case（health / session / skill / context / chat-flow 等）行为预期不变，**无需新增 case**。v0.0.66 是纯 refactor，外部观测行为 1:1 对齐。

> AT 实际跑动遗留 v0.0.67（forked scope 黑盒难观测 + 需真 LLM provider 配置）；UT 已全量回归覆盖。
