# v0.0.101 API 变更日志（ask-question tool + 通用 pending 悬挂机制 + 列表指示器 + workspace 修复）

> API 契约增量（黑盒 AT 依据）。技术权威 `specs/tech/version_logs/v0.0.101/change_log.md` + `change_plan.md`（模块 F）。

## 新增端点

### `GET /session/:id/pending-tool-call`（§3.6）
- 返 `pendingToolCalls` 队首（单个 `PendingToolCall`），只读 peek（不清空/不锁/不 drain）。
- 空队列返 `200` + `{ pending: null }`（非 404）。
- recover 用：切走切回 / 重启后前端 onInit 主动拉（配合 SSE `require_human_input` sticky replay 缺失场景，类比 v0.0.97 GET /inbox seed enqueue）。
- 多 pending 串行展示（INV-4）：peek 仅队首单条；回填一条后下一个变队首 + SSE 切换。

## 扩展端点

### `POST /session/:id/messages`（§3.2）
- body 新增可选 `toolReply?: { toolCallId, handleType, payload }`。
- 含 toolReply → handler 构造 `tool_reply` message（sender.source='tool_reply'）→ `deliverTo`（复用 inbox，INV-5，不独立接口）。
- 不含 toolReply → 原 user query 路径不变。suspended 态接 query（无 toolReply）= 放弃 c 路径。
- 错误码：`400`（toolCallId 空 / handleType 非三分支之一）；`409` `{error:'tool_reply toolCallId mismatch or no pending'}`（peek 队首 toolCallId 不匹配或队列空——INV-4 串行约束，只能回填队首）。
- suspended → markRunning WHERE 加 'suspended'（O6 闸门）。

### `GET /session/:id`（§2.3）
- 响应 `state` 加 `"suspended"`（六态）。
- 新增 `pendingToolCalls: PendingToolCall[]`（落盘，默认 `[]`）。
- `running` 排除 suspended（INV-2）。

### `POST /session/:id/run`（test-only sync wrapper，O9）
- `TERMINAL_STATES` 集合加 `'suspended'`：tool_pending StopReason 触发 markSuspended 后 session 进入 suspended 合法存活态，POST /run（test sync wrapper）await 终态必须把 suspended 视为终态返 `state=suspended`/`stopReason=tool_pending`，否则 /run 在 HITL 场景下挂起致 AT timeout（tool_pending→suspended 是合法 run 退出，promise settle + state=suspended；不算异常）。
- 响应 `state` 终态集合 `idle | interrupted | error | suspended | unknown`（原 v0.0.69 三态 + suspended）。
- 行为不变：deliverTo → await agentRun.promise → poll state 至终态 →返。

## SSE 事件变更（breaking）

### `require_human_input`（agent_event §7）
- payload 从 `{toolCalls: ToolCallBlock[], prompt?}` 改为 `{pending: PendingToolCall}`（单个队首）。
- 进 suspended 时 emit（agent_loop topic）；前端首次弹提问卡。breaking change，本版本一次性改完，不向后兼容旧 payload。

### `session_meta` 广播（§4.2）
- `SessionMetaView.state` 含 `suspended`；`running` 排除 suspended（列表据此亮「?」非 spinner，D6）。

## 不变项

- GET /messages / GET /inbox / POST /abort / POST /messages/:enqueueId/cancel / SSE 三事件（run_start/message_*/run_end）/ session_meta 广播 topic 命名 — 全部不变。
- `require_human_input` 之外无新 SSE event type。
