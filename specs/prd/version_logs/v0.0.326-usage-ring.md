# v0.0.326 — usage 用量环优化

> PRD 增量 | 版本：v0.0.326 | 日期：2026-08-11
> 老板 4 点需求 + 6 问题拍板确认（2026-08-11）

## 1. 需求描述 [v0.0.326]

优化对话上方 topbar 右侧的 token 用量环（`ComponentUsagePanel` + `ComponentUsageRing`）：

1. **环内显示百分比整数**（如 `23%`），去掉环外「Xk/Yk」文字
2. **压缩和清理按钮**从 topbar 外侧移入展开面板右上角（token 用量行右侧对齐）
3. **去掉 hover 气泡 + 去掉展开按钮**；整环 hover 有可点击感官、点击即展开
4. **环水平对齐**下方 chat 右侧功能区（`ComponentChatFloatMenu` 竖排菜单）；展开面板向**左下**展开避开功能区

**所有场景统一**：7 个消费方复用同一 `SectionChatSession` 渲染，改一处全生效，无分场景逻辑。

### 1.1 用户故事

作为用户，我希望 token 用量环简洁直观——一眼看到百分比、点击展开看详情、压缩/清理藏在面板里不占日常空间，以便 topbar 更干净、操作层次更清晰。

**优先级**：P1

## 2. 需求边界 [v0.0.326]

### 2.1 做什么

| # | 改动 | 范围 |

| ① | 环内百分比整数 + 删环外文字 | `ComponentUsageRing` 加文字 + `ComponentUsagePanel` 删 fmtK 文字 |
| ② | 压缩/清理移入面板 | topbar 移除 CompactBtn/ClearBtn → 浮层 head 右侧 |
| ③ | 删 hover 气泡 + 删展开按钮 + 整环可点击 | `ComponentUsagePanel` trigger 区重构 |
| ④ | 环像素对齐 float-menu + 面板左下展开 | topbar right padding 调整 + 浮层定位改向 |

### 2.2 不做什么

- ❌ 不改展开面板**内容区**（大圆环 52×52 + 数字 + 占用率 + 3 分段进度条 + 3 图例 + 累积消耗表格——全保留）
- ❌ 不改 CompactBtn / ClearBtn 组件本身（只改挂载位置）
- ❌ 不改数据链路（`useUsage` / `useSummary` / SSE `session_usage_update` 不变）
- ❌ 环**不脱离 topbar**（老板选方案 B，不移到 right-overlay，拓扑不动）
- ❌ 不改 float-menu / right-overlay / minimap

## 3. 交互设计 [v0.0.326]

### 3.1 收起态（默认）

```
┌─ topbar（px-6 py-3 border-b flex justify-between）───────────────────┐
│  [topbarLeft]        ......                                    [环] │
│                                                         ↑          │
│                                    36×36 圆环，内含「23%」白色文字     │
│                                    整环可点击（cursor-pointer）        │
└──────────────────────────────────────────────────────────────────────┘
                                              ┌────┐
                                              │记忆│  ← float-menu（right-6）
                                              │cron│     环与 float-menu 同一垂直线
                                              │... │
                                              └────┘
```

**收起态变化（vs 现状）**：
- ✅ **环尺寸**：28×28 → **36×36**（stroke 不变 4px）
- ✅ **环内文字**：百分比整数 `Math.round(pct * 100)%`（如 `23%`），`text-fg-2` 统一色（**不变色**，只环 stroke 跟随占用率绿/黄/红）
- ❌ 删「已用/总」`fmtK` 文字（如 `23k/200k`）
- ❌ 删 hover tooltip（累积消耗简表气泡）
- ❌ 删 chevron 展开按钮
- ✅ **整环可点击**：trigger div 加 `onClick={() => setOpen(!open)}` + `cursor-pointer`
- ✅ **hover 感官**：trigger 区域 `hover:bg-bg-warm rounded-lg transition-colors`（沿用现有 hover bg，增强可点击感）；加 `title`/`aria-label` = 「点击查看用量详情」（i18n `usage.clickToExpand`）
- ✅ **topbar 右端**：只留 usage 环（CompactBtn/ClearBtn/竖分隔线全移除）

### 3.2 环内百分比渲染 [v0.0.326]

36×36 圆环内居中渲染百分比文字。实现方式（给 architect 参考）：

```
<div className="relative w-9 h-9 flex items-center justify-center cursor-pointer">
  <ComponentUsageRing used={used} total={total} size={36} stroke={4} />
  <span className="absolute text-[9px] font-bold text-fg-2 font-mono pointer-events-none">
    {Math.round(pct * 100)}%
  </span>
</div>
```

> 环 SVG `aria-hidden`（既有）；百分比文字用绝对定位叠在环正中。`text-[9px]` 在 36px 环内可读（两位数+百分号 ≈ 20px 宽，环内径 28px 够放）。`pointer-events-none` 防文字拦截点击。

**文字色规则**：
- 统一 `text-fg-2`（前景次色），**不跟随占用率变色**
- 只有环 stroke 变色（`usageRingColor`：pct<0.5 success / <0.8 warning / ≥0.8 danger）
- 理由：黄/红文字在小环内对比度不够，统一 fg 色可读性优先（老板 Q6 拍板）

### 3.3 展开态（面板向左下展开）

```
    ┌─ 浮层 300px（absolute，从环的左下方展开）──────────────┐
    │  Token 用量                          [压缩] [清理]       │  ← head 行：标题左 + 按钮右
    │  200,000 context                                        │
    │  ┌──────────┐  23,000 / 200,000                         │
    │  │ 环 52×52 │  占用 12% · 剩余 177,000                   │
    │  └──────────┘                                            │
    │  ▓▓▓░░░░░░ 3 分段进度条（system/messages/tools）          │
    │  ■ system  ■ messages  ■ tools                          │
    │  ── 累积消耗 ──                                          │
    │  来源 | input | cache | output | total                   │
    │  ...                                                     │
    └───────────────────────────────────────────────────────────┘
                                              ┌────┐
                                              │ 环 │  ← trigger（收起态位置）
                                              └────┘
```

**展开态变化（vs 现状）**：
- ✅ **展开方向**：`absolute top-full right-0`（向↓）→ **`absolute top-full` + 右端贴环右缘、向左延伸**（向左下展开）。定位改为 `right-0` 但面板宽度 300px 从环右侧向左展开——即 `absolute` 以 trigger 右缘为基准，面板向左+向下展开。
- ✅ **head 区右侧加 CompactBtn + ClearBtn**：与标题行同行，`flex justify-between`，标题左、按钮组右
- ✅ **面板内容区不变**：大圆环 + 数字 + 占用率 + 3 分段 + 图例 + 累积表格

**面板内 CompactBtn/ClearBtn 位置细节**：
```
<div className="flex items-center justify-between mb-3">
  <div>
    <div className="text-[13px] font-bold text-fg">{t('usage.title')}</div>
    <div className="text-[10px] text-muted mt-0.5 font-mono">{fmtNum(total)} context</div>
  </div>
  <div className="flex items-center gap-1">
    <CompactBtn ... />  {/* 尺寸缩小到 h-7 w-7 适配面板 */}
    <ClearBtn ... />    {/* 同上 */}
  </div>
</div>
```

> CompactBtn/ClearBtn 在面板内尺寸可略缩（`h-7 w-7` 或保持 `h-[30px] w-[30px]`，由 architect 定）。`caps.compact`/`caps.clear && !readOnly` 门控逻辑不变——只通过 props 回调透传给 UsagePanel，由 UsagePanel 内部按 props 决定渲染。

### 3.4 关闭面板

- 点面板外部（document mousedown，既有逻辑）→ 关闭
- 点面板内部 `stopPropagation`（既有逻辑）→ 不关闭
- **再次点环** → `setOpen(!open)` toggle 关闭（新增，因为环现在是 trigger）

## 4. 像素对齐方案（老板 Q4 选方案 B） [v0.0.326]

### 4.1 现状几何

- **topbar**：`px-6 py-3` → 右内边距 24px；`justify-between` 把 topbarRight 推到 topbar 右内缘（距视口右 24px）
- **right-overlay**（float-menu 容器）：`absolute inset-y-0 right-6` → 距视口右 24px
- **两者右缘基准一致**（都是 24px from right edge of chat root）→ 像素对齐可行

### 4.2 对齐目标

usage 环（36px 宽）的**中心线**与 float-menu（`w-8`=32px 宽）的**中心线**在同一垂直线上。

### 4.3 实现方式（给 architect 参考）

topbar 右端 trigger 容器微调 right padding/margin，使环中心线 = float-menu 中心线。由于 topbar `px-6`=24px 和 overlay `right-6`=24px 基准一致，差值 ≈ 环宽度(36)与 float-menu 宽度(32)的半差 2px。具体偏移由 architect 在 change_plan 里精确计算（`pr-0.5` 或 `mr-[-2px]` 量级），PRD 只定义视觉目标。

> **拓扑不动**：环仍在 topbar 的 `topbarRight` slot 内，不脱离 topbar，不移到 right-overlay。
