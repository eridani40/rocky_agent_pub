# v0.0.66 PRD Change Log — context engine assemble/ingest 协议重构（内部 refactor）

> version: 1.0 · 2026-07-04
> 一句话定位：**内部 refactor**——default 与 forked 共用同一套 ingest/assemble 主干逻辑，差异纯靠 `session_store` 扩展点按 scope 选 impl 切换 + summary 驱动 rebuild；主干代码零 `isForked` 分支。**无 API 接口变更、无 UI 变更、无用户可见行为变更**。
> 概念权威源（**PRD 对齐**）：`specs/tech/agent/context/index.md` ④ 原则 11 + `[P0]context_engine.md §3.6`（session_store EP）+ `[P0]context_assemble_detail.md §2`（base_builder 统一 shouldRebuild）。
> 方案锁定：`reqs/[working] v0.0.66/design.md`（用户已确认设计：统一逻辑 + scope 切换实现）。

## 1. 背景与目标

v0.0.40 起 context engine 引入 forked scope 用 buffer 数组（vs default 用持久 store）的特化路径——`ForkedContextPort` 直接 `buffer.push()` 绕过 impl 链，导致 spec 声明的 `buffer_sink`/`buffer_reader`/`append_passthrough` impl 从未被 forked 路径触发（v0.0.49 修复激活）。但 forked 仍有特化分支（base_builder 不复用 prevSnapshot、`if (scopeId === 'forked')` 硬尾写 buffer 等），增加维护成本 + 测试覆盖盲区。

**本版本目标**：彻底消除 ingest/assemble 主干的 isForked 分支——session store 也 EP 化（`SessionStorePoint` exclusive），default + forked 共用同一套主干逻辑，差异纯靠 EP impl 切换。

**非目标**：
- 不变更 API 接口（HTTP 端点契约零变更）
- 不变更 UI（前端无感）
- 不变更 PRD 用户路径（compact / chat / forked agent 行为不变）

## 2. 范围

### 2.1 IN-SCOPE（10 项核心改动）

| # | 项 | 摘要 |
|---|---|---|
| 1 | session store 扩展点化 | 新增 `SessionStorePoint`（exclusive）+ 2 impl（persistent/in_memory） |
| 2 | ingest/assemble 零 isForked | 主干代码无 scope 特殊逻辑，纯 scope 驱动 |
| 3 | system prompt 独立 | 删 `system_prompt` assemble impl；由 context-engine.assemble 独立调 builder（复用规则同 base_builder） |
| 4 | messages 纯对话历史 | system 不在 messages（由 snapshot.system 独立承载）；loop-stage-llm 送 LLM 前 prepend |
| 5 | forked in_memory store | per-session Map；forked run 结束 onRunEnd 调 releaseSlot 清内存槽 |
| 6 | base_builder 统一 shouldRebuild | 无 scopeId 分支；appendNew 按 id 用 transcript 原始版本覆盖 prev（保 tool_call 配对） |
| 7 | 删 4 buffer/system impl | buffer_sink/buffer_reader/append_passthrough/system_prompt（assemble） |
| 8 | forked reducer 对齐 default | forked active 5 reducer（base_builder + 4 清理），与 default 一致 |
| 9 | releaseSlot 重命名 | SessionStoreContract.releaseSlot（vs SessionStore.clearSession 命名分离） |
| 10 | 文件拆分 | ≤300 行约束（context-engine.ts / build-forked-deps.ts / types.ts） |

### 2.2 OUT-OF-SCOPE（遗留 → v0.0.67）

- **forked-scope-bootstrap 运行时 enable/disable 流氓逻辑**：本版本保此逻辑覆盖历史落盘 false drift（v0.0.49 残留累积），v0.0.67 重构（落盘 drift 一次性清理 + bootstrap 不再写 enable）。
- **真 LLM AT 待配 provider**：本版本 UT 全绿 + code review PASS；AT 因 forked scope 黑盒难观测 + 需真 LLM provider 配置，遗留 v0.0.67。
