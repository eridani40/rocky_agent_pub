## 1. 版本主题

**围绕一个目标培养一个 agent**：通过「教室 + 班主任 + 教练 + 训练引擎」，把一个全空的初始学生，经多轮训练迭代，逐步打磨成可用的专家版本，最终可发起会话、可派生到团队。

旧 academy（v0.0.183）已于 v0.0.208 删除；本版当**全新功能**设计，不兼容旧形态。

## 4. 关键用户路径（UC-A ~ UC-G，共 7 条）

对齐 `design.md §8 关键产品 case a-g`，每条路径 = 至少一个 API/E2E case。

| ID | 路径名 | 操作链路简述 | 验证层 |
|---|---|---|---|
| **UC-A** 创建教室 | 进入 Academy → 新建教室 → 填名/logo → 确认 → 教室列表新增 → 进教室详情见班主任入口 | AT（POST /academy/classroom 事务 + 自动建 head session）+ ET（教室列表 → 详情） |
| **UC-B** 创建学生 | 教室详情 → 对话/产品入口 → 建学生 + 初始 0.0 版本 → 学生列表/树显示 | AT（建 student record + 初始 0.0 版本目录）+ ET（学生创建入口 + 列表） |
| **UC-C** 编辑版本内容 | 学生详情 → 选正式版本 → 弹层 md 编辑器 → 改五元组 → 保存 | AT（写 AGENTS.md / version.json / skills）+ ET（弹层 modal view/edit 切换） |
| **UC-D** 发起简单学习训练 | 学生详情 → 发起训练（simple + learning + directive）→ 等候 → coach 跑一轮 → propose → 接受/拒绝 | AT（真调 LLM 跑完 + accept 复制为新正式版）+ ET（训练观察页 + propose 接受） |
| **UC-E** 发起多轮训练式训练 | 学生详情 → 发起训练（multi + training + dataset/grader + maxTurns + directive）→ 观察每轮 → 最终 propose → 接受/拒绝 | AT（真调 LLM 多轮 sample+grade+decide）+ ET（右侧训练视图：每 case 分数 + 临时基线 + 决策） |
| **UC-F** 训练中对话 + subagent 只读观察 | 训练观察页 → head↔coach / 用户↔head/coach 对话；subagent working 时只读可点，跑完消失 | AT（a2a 投递 + deliverTo inbox 事件）+ ET（观察页入口 + 无输入框只读 chat） |
| **UC-G** 正式版发起会话 | 学生详情 → 选正式版本 → 发起会话 → 用版本目录 + academy-student kind 建会话 → 聊天 | AT（建 academy-student session）+ ET（chat 页复用 playground-rocky） |

**路径数 = 7 条**（design.md §8 case a-g 逐条对齐）。
