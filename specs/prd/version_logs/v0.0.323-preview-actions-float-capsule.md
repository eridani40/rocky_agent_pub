# v0.0.323 PRD — 预览区操作按钮 → 会话区右侧功能区悬浮胶囊容器

> since: v0.0.323
> status: draft
> owner: prd

## 1. 需求背景

**现状**（v0.0.320）：预览区正文区（`pv-content`）有 3–5 个**散落悬浮按钮**（`component-preview-floating-actions.tsx`），靠 `opacity-0 group-hover/pv-content:opacity-100` 显隐——hover 正文区才浮现，按钮之间各自独立、无容器包裹。

**问题**：散落按钮缺乏整体感，与聊天区右侧的竖排胶囊工具条（`component-chat-float-menu.tsx`）视觉风格不一致。

**目标**：改成 chat-float-menu 那种**带背景/边框/阴影的竖排胶囊容器**，按钮收入容器内，位置仍在预览区一侧（右缘偏上）。按钮范围保留全部 5 个（编辑/保存/撤销/格式化/校验），全部收入胶囊容器。

## 2. 改造范围（A+A 确认 + 老板变更 08-11）

### 2.1 容器改造：散落按钮 → 胶囊容器

**改造前**（`component-preview-floating-actions.tsx`）：
- 外层 `<div>` 无背景无边框，仅 `flex flex-col gap-1.5`，按钮各自带 `bg-surface border shadow-sm`。
- 显隐：`opacity-0 group-hover/pv-content:opacity-100`（hover 正文区才浮现）。

**改造后**（参照 `component-chat-float-menu.tsx` L88）：
- 外层容器：`flex flex-col gap-1 rounded-xl border border-border bg-surface p-1 shadow-sm`
- 按钮：`h-8 w-8 rounded-lg text-muted transition-colors hover:bg-bg-warm hover:text-fg`（去掉每个按钮自带的 border/bg/shadow——容器统一提供视觉边界）
- 保存按钮（primary）：容器内仍需区分主色——`bg-accent text-white hover:bg-accent-hover`（保留 primary 区分，嵌在容器 gap 内，不破坏容器边界）

### 2.2 按钮范围：5 个全放胶囊容器 ✅ 老板变更确认（08-11）

> **变更**：初版 PRD 拟将格式化/校验移到编辑器内部，老板看完架构后指出「编辑器内部没地方放」，改为 **5 个按钮全部留胶囊容器**。

| 按钮 | 图标 | 位置 | tooltip（中文） | 说明 |
|------|------|------|-----------------|------|
| 编辑 | PencilIcon | 胶囊·只读态 | 「编辑」 | 进编辑态 |
| 保存 | SaveIcon | 胶囊·编辑态 | 「保存」 | primary 色 |
| 撤销 | UndoIcon | 胶囊·编辑态 | 「撤销」 | 放弃修改回只读 |
| 格式化 | AlignIcon | 胶囊·编辑态·structured only | 「格式化」 | 格式化 draft |
| 校验 | CheckSquareIcon | 胶囊·编辑态·structured only | 「校验」 | 校验 draft |

### 2.3 按钮顺序 ✅ 老板变更确认（08-11）

**只读态**（mode='view'）：自上而下仅 1 个按钮

| 顺序 | 按钮 |
|------|------|
| 1 | 编辑 |

**编辑态**（mode='edit'）：自上而下

| 顺序 | 按钮 | 条件 |
|------|------|------|
| 1 | 保存 | 始终 |
| 2 | 撤销 | 始终 |
| 3 | 格式化 | structured only |
| 4 | 校验 | structured only |

> **顺序逻辑**：保存（最高频/确认动作）置顶 → 撤销（退出编辑）→ 格式化/校验（structured 辅助操作）排在最后。plain/code/md 编辑态只有 保存 + 撤销（2 个按钮）。

### 2.4 显隐策略：常驻胶囊

**决策**：改成**常驻显示**（去掉 `opacity-0 group-hover:opacity-100`）。✅ **老板已确认（2026-08-11）**

**理由**：
- 参照物 chat-float-menu 是常驻的（不依赖 hover 显隐）
- 散落按钮 hover 才现是为了「不遮挡正文」，但胶囊容器体积小（最多 2 按钮 + padding，宽 ~40px），挂在右缘偏上不遮挡核心阅读区
- 常驻后用户随时可见可点，交互更直接

**布局稳定性**：胶囊容器 `absolute right-3 top-4 z-[5]`，position 固定不随内容滚动——按钮出现/消失（mode 切换只读↔编辑）不影响正文布局（容器 absolute 定位，脱离文档流）。

### 2.5 Tooltip（新增）✅ 老板变更确认（08-11）

**需求**：鼠标悬停按钮 ~1 秒后弹出文字 tooltip（老板原话「你那个按钮可能没人能看懂」）。

**实现**：每个 `<button>` 设 `title` + `aria-label`（浏览器原生 title 即 hover 延迟弹出 tooltip，无需额外组件）。

| 按钮 | tooltip 文案（zh-CN） | i18n key |
|------|----------------------|----------|
| 编辑 | 编辑 | `workspace.preview.edit` |
| 保存 | 保存（保存中=「保存中…」） | `workspace.preview.save` / `saving` |
| 撤销 | 撤销 | `workspace.preview.undo` |
| 格式化 | 格式化 | `workspace.preview.format` |
| 校验 | 校验 | `workspace.preview.validate` |

> i18n key 沿用现有，无新增。`title` 属性值 = `t('workspace.preview.xxx')`。

### 2.6 图标 ✅ 老板变更确认（08-11）

**基准**：`preview-icons.tsx` 现有 5 个图标（PencilIcon / SaveIcon / UndoIcon / AlignIcon / CheckSquareIcon），均为单色 feather stroke 风格（`strokeWidth=2, strokeLinecap='round'`）。

**约束**：单色 stroke 风，不要彩色 / emoji。

**⚠️ 待定**：老板要看实物截图后最终定图标。当前以 preview-icons.tsx 现有图标为基准实现，截图后可能微调。

## 3. 落位（挂载点）

**挂载位置不变**：仍在 `section-preview-area.tsx` 的 `pv-content` 内（L168–L206），`absolute right-3 top-4 z-[5]`。

```
<div className="pv-content group/pv-content flex-1 min-h-0 flex flex-col relative">
  {viewer 或 editor}
  {activeTab && loadState==='loaded' && (
    <ComponentPreviewFloatingActions ... />  ← 胶囊容器，absolute 悬浮
  )}
</div>
```

**去掉 `group/pv-content`**：不再需要 group-hover 控制显隐。`pv-content` 的 `group/pv-content` class 可保留（未来可能其他子件用），但 floating-actions 不再依赖它。

## 4. 交互不变项（复用现有逻辑）

以下逻辑**完全不变**，仅触发按钮的视觉容器变了：

- **编辑守卫**：只读态点「编辑」→ `setMode(tabId, 'edit')`（无守卫）
- **撤销**：编辑态点「撤销」→ `setMode(tabId, 'view')`（直接回只读，不走 dirty modal——用户主动放弃）
- **保存**：编辑态点「保存」→ `editorRef.current?.save()` → `saveTab` → workspace 源带 `expectedVersion`（409 → 冲突 modal）/ absolute 源 last-write-wins
- **dirty 守卫**：切/关 tab / 收起预览区时，当前 tab dirty → dirty modal（保存并切换/放弃/取消）——不受本次改造影响
- **409 冲突**：保存冲突 → conflict modal（重载/覆盖）——不受本次改造影响

| ID | 用户操作链路 | 预期结果 |

| UC-2 | 只读态点击「编辑」→ 进入编辑态 | 胶囊容器内按钮变为：保存(1) + 撤销(2)（plain/code/md）或 保存+撤销+格式化+校验（structured）；textarea 出现 |

## 8. i18n

无新增 key。编辑/保存/撤销/格式化/校验的 i18n key 沿用 `workspace.preview.*`（edit / save / saving / undo / format / validate / formatFail / validateFail / validateFailLine / validateOk）。tooltip 文案复用同一 key。

## 9. 边界

- **image 不进预览区**：不受影响（仍走 ws-image-viewer 弹层）
- **code 分类无格式化/校验**：编程语言后缀 → 'code' → 行为 = plain（编辑器内部不渲染格式化/校验按钮）
- **absolute IPC 源 v1 无冲突检测**：不受影响
- **收起态**：预览区收起时 capsule 随 pv-content 一起消失（aside 宽=0），无残留
