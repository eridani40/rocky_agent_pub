# PRD v0.0.177 — 粘贴剪切板图片到输入区

## 一句话
剪切板含图片内容（非文件）时，在聊天输入框粘贴 → 图片保存到 `ws/images` → 当前光标位置插入该 image 的 @mention pill。

## 背景与范围划界（用户确认）
- **现状**：输入框粘贴无任何图片处理（greenfield）；mention 已有 4 type（file/skill/workitem/member），图片可作为 `file` 复用
- **本版本只做「输入」**：粘贴 → 存盘 → 插 @file pill
- **不在本版本**：① 下游 agent 用 see_image 工具读图（v0.0.141 已有能力，pill 插入后 agent 自己消费）；② 多模态（图片直接传模型）

## 用户可感知行为
1. 用户截图（或复制图片）→ 剪切板含图片内容
2. 在聊天输入框（ChatComposer，playground / studio member / studio squad 三页共用）Cmd/Ctrl+V 粘贴
3. 图片保存到当前 session 的 `ws/images/image-<ulid>.<ext>`（目录不存在则创建）
4. 当前光标位置出现一个 @file mention pill（label = 文件名，如 `image-xxx.png`），与手动 @file 选图片视觉一致
5. 用户可继续编辑、删除该 pill、发送；发送后落库为 `<mention type="file" path="images/..."/>`，下游 LLM 可用 see_image 读

## 关键用户路径
- **路径1（主）**：截图 → 输入框粘贴 → 图片保存 + 出现 @file pill → 发送
- **路径2（多图）**：剪切板含多张图片 → 粘贴 → 依次保存 + 依次插入多个 @file pill
- **路径3（图片+文本混粘）**：剪切板同时有图片和文本 → 优先处理图片（保存+插 pill），文本不重复插入

## 交互细节
- 粘贴纯文本（无图片）：保持 Tiptap 默认行为，不变
- 后缀推导：`image/png→png`、`image/jpeg→jpg`、`image/gif→gif`、`image/webp→webp`
- 落盘失败（权限/磁盘）：提示用户，不插入 pill
- 非图片文件粘贴：不在本版本

## UI 对齐（specs/ui + specs/tech）
- **复用 `file` mention type**（specs/tech/mention/message-content.md §3.1），不新增 type —— INV-2 type-agnostic 保证
- pill 视觉：复用 MentionPill primitive + 现有 file glyph（specs/ui/components/mention-pill.md），零改动
- paste 入口：ChatComposer 的 Tiptap `editorProps.handlePaste`（specs/ui/components/chat-composer.md）
- 保存端点：扩 specs/api/overall/04-agent-session.md §2.6 workspace 端点组（路径白名单安全范式同款）

## 不覆盖（明确排除）
- see_image 工具调用（已有能力）、多模态、非图片文件粘贴、图片编辑/预览/压缩
