交互说明
  • 两层结构：外层方案卡片（名称 / 模型数 / 模型名 / 挂载状态）→ 点击进入详情编辑，返回回列表
  • 拖拽排序：拖动行首 ⋮⋮ 手柄，松手后序号自动重排（手柄为唯一拖拽源，弹层内拖选不受影响）
  • 时间限制：灰时钟 = 全天可用；点开弹层默认全灰（未配置时段），选中变深 = 该小时可用；确定保存（1-23 格），清除定时回全天
  • 弹层底部：左侧实时显示已选时段（与 hover tooltip 同格式），右侧「清除定时」「确定」
  • 熔断状态：🟢 正常 / 🔴 异常带倒计时 / 🟡 观察中；熔断参数在详情底部高级区
  • 开关：黑色 = 启用；关闭后行半透明灰显

设计 token：CSS 变量内联自 app/web/src/styles/tokens.css（light-only 银灰 v0.0.165）。
