# v0.0.166 Skill 市场调研 Part C — 民间/第三方 skill hub 与中心化托管平台

> 本轮聚焦「自建站、聚合/托管 skill、可能有下载量/评分/公开 API」的第三方平台，对官方 anthropics/skills + Claude Code marketplace + MCP registry（前两轮已覆盖）做补充。
> 限时聚焦调研，12 次工具调用；查不到的项一律标「未找到」，未编造。

## 结论先行（TL;DR）

1. **最值得对接/参考的是 ClawHub（openclaw）**：唯一明确对外宣称「public skill **registry** + CLI-friendly API + 安装遥测（install counts）」的平台，格式基于 `SKILL.md` + YAML frontmatter，社区活跃度高（GitHub 9.2k stars、2344 commits、3000+ skills、宣称 15K+ 日安装）。但**具体 HTTP registry 端点 URL 在公开文档里没直接列出**，需拉 repo 的 schema 包/CLI 源码确认——这是对接前必须落实的关键 gap。

2. **格式高度收敛到 Anthropic `SKILL.md`**：ClawHub / SkillsMP / Agensi / Skills Directory / Manus **全部**以 `SKILL.md`（markdown + frontmatter）为核心格式，与我们的既定格式兼容。**格式不是对接障碍，公开 API 的有无才是。**

3. **多数「hub」其实是网页目录 / CLI 安装器，而非可编程 API**：Agensi（2147 skills）、aitmpl（1000+ 组件）、Skills Directory（宣称 9.6 万索引 skill）主要靠网页浏览 + CLI/npm 安装，**未公开可直接调的 search/list/install REST 端点**（aitmpl 有静态 `/counts.json`、`/plugins.json` 可扒，算半可对接）。

4. **真实质量信号普遍弱**：只有 ClawHub 有 install counts + star/comment；Agensi 有分类/周榜但无公开安装数/评分；Skills Directory 独特点是**安全扫描分级（A 级 + Security Badge + VirusTotal）**而非人气评分。**没有一个平台提供像 npm 那样成熟的下载量 + 评分 + 评论三件套。**

5. **相比官方 anthropics/skills，民间源多提供的价值**：① 聚合跨来源 skill（规模远超官方，Agensi 2147 / ClawHub 3000+ / Skills Directory 声称 9.6万）；② 安装遥测/人气信号（ClawHub install counts、aitmpl trending）；③ 安全扫描背书（Skills Directory）；④ 变现/付费（Agensi Stripe）；⑤ 一键安装体验（SkillsMP→Manus、CLI 安装器）。官方 repo 只是纯 GitHub 目录，无这些运营层信号。

6. **建议**：对接优先级 = **ClawHub（先扒 repo 确认 API 契约）> aitmpl（静态 JSON 可抓取）> 其余作为「网页目录参考/内容源」**。我们要么对接 ClawHub registry API，要么直接沿用「GitHub repo + SKILL.md」的 git 安装范式（与所有平台格式兼容，零对接成本）。

## 平台逐个详解

### 1. ClawHub / OpenClaw（用户点名）★ 最相关
- **域名/来源**：`clawhub.ai`、`docs.openclaw.ai`、repo `github.com/openclaw/clawhub`
- **定位/运营方**：OpenClaw 组织运营的 **public skill + plugin registry**（「the Skills Marketplace for Claude Code」）。可发布、版本化、搜索文本类 agent skills 及代码 plugin。
- **公开 API**：宣称有「**CLI-friendly API**」，路由定义在共享 schema 包里；**但公开文档/blog 未列出具体 HTTP 端点 URL 与 base domain**（未找到明确端点）。发布需 CLI 认证；**无认证的公开只读 API 是否可用未明确**——对接前须拉 `openclaw/clawhub` repo 的 schema 包 + CLI 源码确认 search/list/install 路由。
- **skill 格式**：`SKILL.md` + YAML frontmatter（声明 env vars、binaries 等运行时需求）。与 Anthropic 格式一致（文档未特意强调「Anthropic 兼容」，但结构相同）。
- **安装机制**：CLI（`clawhub install`）或 Nix 包（`nix-clawdbot`）。
- **质量信号**：有「minimal install telemetry」→ **install counts**（登录用户）；用户可 **star + comment**；admin/moderator 审核 curate；VirusTotal Verified 徽章（blog 提及）。无正式评分体系。
- **规模/活跃度**：blog 称 **3000+ published skills、15K+ daily installs**；repo **9.2k stars / 1.4k forks / 2344 commits**，活跃。

### 2. SkillsMP / SkillMP（用户点名，Manus 相关）
- **域名**：`skillsmp.com`（有中文站 `/zh`、`/docs`）
- **定位/运营方**：面向 Claude & Codex 的「Agent Skills Marketplace」，**深度集成 Manus**（一键在 Manus 内安装）；具体运营方未署名。
- **公开 API**：文档提「REST API reference」+ 一个 search URL，**但未列出具体 list/install 端点**（未找到）。
- **skill 格式**：`SKILL.md` markdown，明确对齐 Anthropic 格式（同时讲 MCP & Codex）。
- **安装机制**：Manus 内一键安装。
- **质量信号 / 规模 / 活跃度**：收录数量、下载量、评分、verified、分类、活跃度**均未找到**。
- **同类**：`awesomeskill.ai`（Awesome Skills，同类聚合站，本轮未深入）。

### 3. Manus 官方 skill 市场
- **来源**：`manus.im/docs/features/skills`
- **现状**：目前只有官方 **"official library"** 预置 skill；**「dedicated Manus Skills website」作为社区中心 hub 仍在规划中（未上线）**。
- **skill 格式**：`SKILL.md` 为核心，包可为 `.zip` / `.skill` 文件 / 文件夹。
- **安装机制**：保存成功对话、上传本地文件、选官方库、或**导入 GitHub repo 链接**。
- **公开 API / 下载量 / 评分 / 活跃度**：均未找到（官方库尚无市场化运营层）。
- **判断**：短期不可对接（无公开市场/API），但格式兼容，可作内容源关注其 hub 上线。

### 4. Agensi（agensi.io）
- **定位/运营方**：「AI Agent Skills Marketplace」，Agensi team 运营，**430+ creators**。
- **公开 API**：**未找到**公开 search/list/install 端点 URL。
- **skill 格式**：`SKILL.md` open standard。
- **安装机制**：agent 直接读 `SKILL.md`，「instant」交付（无专用 CLI 强调）。
- **质量信号**：分类/agent/价格/兼容性筛选、「Weekly Winners」周榜、recent updates；**但无公开 install counts、无公开评分/评论体系、verified 徽章未提**。
- **规模**：**All Skills (2147)**。
- **变现**：支持付费/免费，Stripe 处理 purchases/payouts/refunds（少见的商业化 skill 市场）。

### 5. LobeHub（lobehub.com）
- **现状**：`lobehub.com/agents` 本轮返回 **404**（URL 可能已变，如 `/discover/assistants`），未能抓取具体数据。
- **一般认知（未在本轮验证）**：LobeHub 有 agent/assistant/plugin/MCP 的 discover 市场，格式偏其自有 agent 配置（system role + 元数据），**与 Anthropic SKILL.md 非同一格式**；面向 LobeChat 生态而非 Claude skill。
- **判断**：格式不兼容 + 本轮未验证到 skill 专用 API → **可对接性低**，标「待进一步验证」，不建议优先。

### 6. Skills Directory（skillsdirectory.com）
- **定位/运营方**：「security-first directory」for Claude AI agent tools；个人运营（GitHub/X handle `aggarcinuno` / `boatsidejawn`）。
- **公开 API**：footer 有 API 文档链接，**但未列出具体端点 URL**（未找到）。搜索走站内 URL 参数。
- **skill 格式**：兼容 `SKILL.md`，附编写指南。
- **安装机制**：开源 CLI `openskills`（`npm install -g openskills`）。
- **质量信号**：独特——**安全扫描分级（多数得 A 级）+ Security Badge（malware/injection 扫描）+ VirusTotal**；无个人下载量、无人气评分。
- **规模/活跃度**：宣称 **96,920 indexed skills**（数字最大，疑含全网 GitHub 索引）；CLI 10,616 stars；有「new imports queued」的安全分析队列，活跃。

### 7. aitmpl.com / claude-code-templates（davila7）
- **定位/运营方**：davila7 的「CLI tool and marketplace for managing Claude Code components」（网页目录 = `aitmpl.com`，CLI = npm 包 `claude-code-templates`）。
- **公开 API**：**有可抓取的静态 JSON**——前端 JS fetch `/counts.json`、`/plugins.json`（半 API，可爬取组件清单 + 计数）。非正式 REST，但**实际可对接抓数据**。
- **skill 格式**：Claude Code 组件（skills/agents/commands/hooks/MCP/plugins），skill 走 `SKILL.md` 体系（文本未明确细节）。
- **安装机制**：npm 包 `claude-code-templates`（Node 18+ + Claude Code CLI）。
- **质量信号**：有 **Trending** 区、Stack Builder；`/counts.json` 提供计数；无公开评分/评论。
- **规模**：**1000+** agents/commands/skills/settings/hooks/MCP。

### 8. 其他/顺带
- `claudeskills.info`、`skillsllm.com`、`terrylica/cc-skills`、`numman-ali/n-skills`：均为同类聚合目录/GitHub marketplace，本轮未深入，特征与上述目录站同质（SKILL.md 格式 + git/CLI 安装 + 无成熟公开 API）。国内活跃平台本轮未检索到明确候选（如需覆盖国内需补一轮中文检索）。

## 相比官方 anthropics/skills，民间源多提供了什么
- **规模聚合**：官方 repo 仅少量官方 skill；民间站聚合跨来源，动辄千到数万条。
- **人气/安装遥测**：ClawHub install counts、aitmpl trending + counts.json（官方 repo 无）。
- **安全背书**：Skills Directory 安全扫描分级 + VirusTotal + Security Badge、ClawHub VirusTotal Verified（官方无扫描运营层）。
- **变现**：Agensi 付费 skill + Stripe（官方纯开源）。
- **一键安装体验**：SkillsMP→Manus 一键、各站 CLI/npm 安装器（官方靠手动 clone/copy）。
- **短板**：均无 npm 级成熟的「下载量+评分+评论」三件套；真正可编程的公开 REST API 稀缺——多数是网页目录 + CLI，**对接需扒源码或爬静态 JSON**。

## 对接建议
1. **若要对接现成平台**：优先 ClawHub —— 先 clone `github.com/openclaw/clawhub` 读其 schema 包/CLI 源码，确认 registry 的 search/list/install HTTP 端点与鉴权模型，再决定；其次 aitmpl 的静态 JSON 可低成本抓取内容 + 计数。
2. **若追求零对接成本**：直接采用「GitHub repo + `SKILL.md`」的 git 安装范式——与本轮所有平台格式兼容，我们自建 search/install 后端即可，不依赖任何第三方 API 稳定性。
3. **质量信号**：可参考 Skills Directory 的「安全扫描分级 + 徽章」做法（比人气评分更适合 skill 这种可执行内容的信任建立）。
