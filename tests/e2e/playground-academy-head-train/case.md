## Use Case
作为 Rocky 的个人用户，我已在教室建好学生「记录员1」。我对**班主任（head）说"训练记录员1"**，期望班主任：**认识这个学生**（不说"不认识学生"）→ **发起训练**（起训练任务）→ 训练跑完后**能讲清"训练结果 = 学生版本五元组"** → 能**采纳**生成新正式版。验证 v0.0.215 修复后 head 真能完成「发起训练」这件本职。

## 前置条件
- env.sh 已起好环境（headless 或 electron 模式），独立 DATA_DIR（首次进入应为空态，无教室）。
- LLM provider 可用（minimax 优先；head/coach 都会真调 LLM，耐心等）。

## 操作目标（编号步骤）

1. **进入 Academy 板块**：照 `specs/ui/overall/00-app-guide.md` §2/§3.3——nav-rail 顶部业务区「Academy」🎓 落到 academy 页。

2. **建教室（自动建班主任）**：点 sidebar「+ 新建教室」，起名字（如「会议纪要」）创建 → 落教室详情页（`12-academy.md` §3）：左侧出现**班主任对话区**（「班主任 · ● 在线 · 随时可聊」类文案 + 消息流 + 输入框）。

3. **建学生「记录员1」（自动建 0.0 初始版本）**：在「学生」tab 点「+ 添加学生」，名字填「记录员1」创建 → 学生卡片出现在网格（0.0 初始正式版自动就位）。

4. **【核心】对班主任说"训练记录员1"**：在左侧**班主任对话区输入框**输入「训练记录员1」（或「帮我训练一下记录员1这个学生」）发送。**耐心等 head 真调 LLM 回复**。
   - **观察 4.1 — head 认识学生**：head 的回复**不应说**「不认识学生 / 没有学生列表 / 没有管学生 / 找不到学生 / 没有持久化的学生」这类认输话术；应认出「记录员1」这个学生（可提到它的版本/状态）。
   - **观察 4.2 — head 发起训练**：head 应实际**发起训练**（不是只说"我帮你训练"）——随后应能看到训练任务被创建（可切到「训练任务」tab 或等 head 引导进训练观察页确认任务在推进）。
   - **观察 4.3 — head 知道训练结果**：训练推进/跑完后（coach 自主跑，耐心等待），问 head「训练结果是什么/怎么样了」，head 应能讲清**训练结果 = 学生版本的五元组**（System Prompt/AGENTS.md、Skills、Memory、模型、Tools 这类），而不是说"不知道"。
   - **观察 4.4 — 采纳生成新正式版**：结果就绪后（或训练中任意时刻——v0.0.221 采纳是旁路，不限时机），在**学生详情页版本树点过程版的「采纳」按钮**（采纳是 UI inline 入口 → POST adopt，非 head 工具调用——head 无 adopt 权限）→ 应生成一个**新正式版本**（版本树可见 formal x.0 + 「采纳自 v{过程版}」副标题；task 状态不变仍在产）。

## 验收口径（executor 自由心证）
- **pass**：4 步全走通——head 认出学生（无认输话术）+ 实际发起训练（任务推进）+ 讲清结果=版本五元组 + 采纳生成新正式版，无瑕疵。
- **small**：走通了但有小瑕疵（head 措辞啰嗦/某步要追问一次才推进/视觉小问题），不影响「head 认识学生并发起训练」这条主线。
- **blocking**：head 不认识学生（说"没有管学生/找不到学生"等认输话术）/ head 发起不了训练（说"我没有这个工具/无法发起"或一直空转不创建任务）/ head 不知道训练结果是什么 / 采纳入口不出现——**任一命中即 blocking（复刻旧问题复发）**。
