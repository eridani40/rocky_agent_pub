# playground-session-pin — 会话列表即时排序 + 置顶

> 一次性 case（v0.0.231，非入库）：验证 playground 会话列表「统一排序 + 置顶」主链路。
> 纯自然语言，零断言零录制；executor 读 case.md + app-guide 按 snapshot 文案/位置自选定位方式。
> PRD 路径源：`specs/prd/version_logs/v0.0.231.md` §2（UC-231-1~7）+ §3（P-A~P-D）。

## Use Case
作为 Rocky 的个人用户，我希望 playground 会话列表「谁最新谁浮上」且能置顶常用会话：
新建会话出现在列表（非置顶组）最上面、旧会话聊完浮到组内顶、右键置顶后进置顶组（pin 图标 + 背景加重）、取消置顶按原对话时间归位。

## 前置条件
- env.sh 已起好环境（headless 或 electron 模式）。
- LLM provider 可用（minimax 优先；executor 看 app 内可用 provider 选）。
- 已有 2 条以上历史会话（不足则先建：新建会话并各发一条消息，使列表有层次）。

## 操作目标（编号步骤）

1. **进入 Playground**：照 `specs/ui/overall/00-app-guide.md` §3.1——从 nav-rail 点 Playground 入口，落到 chat 页，左侧出现会话列表栏。
2. **新建会话即时在顶（P-A / UC-231-1）**：点会话列表栏「新建会话」按钮 → 观察列表：新会话出现在最上面（无置顶会话时为全表第 1 条），不再沉底。
3. **对话即时浮上（P-B / UC-231-2）**：选中列表中部的一条旧会话 → 发一条简单消息（如「你好」）→ 等 LLM 回复完成 → 观察列表：该会话浮到列表（其分组内）最上面，无需刷新。
4. **右键置顶（P-C / UC-231-4）**：右键列表中部一条非置顶会话 → 浮层菜单中出现「置顶」项（在「复制 Session ID」之上）→ 点「置顶」→ 观察：该会话进入列表顶部置顶组；该 item 最右侧出现常驻 pin 图标、背景比非置顶项加重（灰一档）。
5. **置顶组内浮上（UC-231-5，可选）**：在刚置顶的会话里再发一条消息 → 回复完成后观察：该会话仍在置顶组内最上面，不跌出置顶组。
6. **取消置顶（P-D / UC-231-6）**：右键该已置顶会话 → 菜单项变为「取消置顶」→ 点击 → 观察：pin 图标与加重背景消失；会话回到非置顶组，按它的对话时间归位（不一定回顶部）。
7. **回归确认**：置顶/排序过程中 active 选中态、未读红点、删除按钮、右键「复制 Session ID」行为无异常；列表 header / 新建按钮无位移。

## 验收口径（executor 自由心证）
- **pass**：步骤 1-7 全走通——新建在顶、对话浮上、置顶进组且 pin 图标 + 背景加重可见、取消置顶按原对话时间归位；无错位/重复项/闪烁。
- **small**：主链路走通但有瑕疵（如视觉细节小偏差、文案微差、偶发需多等一拍才归位）。
- **blocking**：右键菜单无「置顶」项 / 点了无反应（分组不变）/ 排序不归位（新建沉底、对话不浮上）/ pin 图标或背景完全不可见 / 关键元素找不到或 API 报错。
