# 团队状态入口挪 chat 浮菜单（防套娃）

## Use Case
用户在 studio 会话中通过 chat 右侧浮菜单打开团队状态弹层，查看成员状态并进入成员对话，验证入口位置 + 防套娃逻辑。

## 前置条件
- 已进入 studio 板块，选中一个有成员的 squad
- 进入一个成员单聊会话（chat 页面）

## 操作目标

1. **chat 右侧浮菜单** → 可见 5 个按钮（记忆/定时/skills/团队状态/todo），**团队状态在第 4 位（todo 上方），todo 保持最后**
2. **点击团队状态按钮** → 弹出 L3 modal 弹层（与 memory/cron 等弹层同形态），显示成员状态（running 上/idle 下 + presence）
3. **topbar** → 不再有团队状态入口（268 的 topbar entry 已移除）
4. **防套娃**：当前会话所属成员那一行**不显示进入对话 icon**；其他成员行 hover 显示进入 icon
5. **点击其他成员行的进入 icon** → 跳转到该成员会话
6. **关闭弹层**：✕/遮罩/Esc 三路均可关闭

## 验收口径

- **pass**：入口在浮菜单第 4 位、弹层正常、防套娃正确、topbar 无旧入口
- **small**：功能正确但视觉微差（badge 位置、间距）
- **blocking**：入口不在浮菜单 / 弹层不弹 / 自己那行仍有进入 icon（套娃）/ topbar 仍显示旧入口
